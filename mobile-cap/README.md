# Prakruthivanam Mobile App

Capacitor 8 shell around the `pvsecommerce` React + PWA app.
The **same codebase** ships as:

| Target | How |
|--------|-----|
| Web (PWA) | Deploy `pvsecommerce/dist` to any static host |
| Google Play | Signed AAB from this folder |
| Apple App Store | IPA built on Mac (see `ios-scaffold/README.md`) |

## Quick start — Android debug APK

```powershell
# From repo root
cd mobile-cap

# 1. Build the React app
npm run build:web       # runs: cd ../pvsecommerce && npm run build

# 2. Copy dist → www (Capacitor webDir)
npm run copy:dist

# 3. Sync Capacitor plugins into android/ project
npm run sync:android    # runs: npx cap sync android

# 4. Build a debug APK
cd android
.\gradlew.bat assembleDebug
```

The APK is at:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

### Sideload the APK to a device

```powershell
# Enable Developer options + USB debugging on the phone, then:
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

Or transfer the file to the phone and open it.

## Release build (Google Play AAB)

### 1. Generate the signing keystore (one-time)

```powershell
keytool -genkey -v `
  -keystore keystore/release.jks `
  -alias prakruthivanam `
  -keyalg RSA -keysize 2048 -validity 10000 `
  -dname "CN=Prakruthivanam, OU=Mobile, O=Prakruthivanam Agri Pvt Ltd, L=Visakhapatnam, ST=Andhra Pradesh, C=IN"
```

### 2. Create `keystore/keystore.properties`

```properties
storeFile=../../keystore/release.jks
storePassword=YOUR_KEYSTORE_PASSWORD
keyAlias=prakruthivanam
keyPassword=YOUR_KEY_PASSWORD
```

**NEVER commit these files — both are gitignored.**

### 3. Build signed AAB

```powershell
npm run build:web
npm run copy:dist
npm run sync:android
cd android
.\gradlew.bat bundleRelease
```

The AAB is at:
```
android/app/build/outputs/bundle/release/app-release.aab
```

### 4. Upload to Google Play Console

1. Go to Play Console → Your app → Testing / Production → Create new release.
2. Upload `app-release.aab`.
3. Fill in release notes, roll out.

## Android App Links (assetlinks.json)

Android App Links let the OS open `prakruthivanam.com/*` URLs directly in the app.

The backend serves `GET /.well-known/assetlinks.json`. You need to set the
`ANDROID_CERT_SHA256` environment variable on the backend server:

```bash
# Get the SHA256 fingerprint from your keystore
keytool -list -v -keystore keystore/release.jks -alias prakruthivanam | grep "SHA256:"

# Set it on the server
ANDROID_CERT_SHA256="AA:BB:CC:..."
```

## iOS — Apple App Store

> **Requires a Mac with Xcode 15+.** See `ios-scaffold/README.md` for
> step-by-step instructions.

### High-level flow

1. On Mac: `npm run build:web && npm run copy:dist && npx cap add ios && npx cap sync ios`
2. Run `@capacitor/assets generate --ios` to create icons/splashes.
3. Open in Xcode: `npx cap open ios`
4. Set signing team + bundle ID `com.prakruthivanam.shop`.
5. Add push notifications capability.
6. Archive → Distribute → App Store Connect → TestFlight.

### Before App Store submission

- Switch backend to HTTPS. Remove the `NSExceptionDomains` ATS entry
  in `Info.plist.additions.xml`.
- Set `APPLE_TEAM_ID` env var on the backend so `/.well-known/apple-app-site-association`
  returns the correct team-prefixed app ID.

## PWA (installable web app)

Deploy `pvsecommerce/dist` to your CDN / static host. The service worker
(`sw.js`) is auto-generated by `vite-plugin-pwa`.

**Minimum install criteria (Chrome DevTools → Lighthouse):**
- HTTPS required.
- Manifest with icons + `display: standalone`.
- Service worker with `fetch` handler.

**Install prompt** appears automatically when the user visits twice and has
the app in the background for a few seconds. Our `PwaInstallPrompt` component
handles the `beforeinstallprompt` event to show a native-looking banner.

## Env vars reference

| Variable | Where | Purpose |
|----------|-------|---------|
| `ANDROID_CERT_SHA256` | Backend | SHA256 fingerprint for `assetlinks.json` |
| `APPLE_TEAM_ID` | Backend | 10-char Apple team prefix for `apple-app-site-association` |
| `KEYSTORE_PATH` | Android CI | Path to `release.jks` |
| `KEYSTORE_PASSWORD` | Android CI | Keystore password |
| `KEY_ALIAS` | Android CI | Key alias (default: `prakruthivanam`) |
| `KEY_PASSWORD` | Android CI | Key password |

## Version bumps

Edit `android/app/build.gradle`:
```gradle
versionCode 3          // increment by 1 for every Play Store release
versionName "2.1.0"    // semver displayed in store listing
```

For iOS, bump `CFBundleVersion` and `CFBundleShortVersionString` in
`ios/App/App/Info.plist` (or via Xcode → General → Identity).
